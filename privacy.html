Last updated: 2026-09-22

Linear Assistant is a Chrome extension that shows, inside Linear's cycle view, how much open work each person carries against the working days they have left. This page explains exactly what data it touches and what it does not do.

What we collect

Nothing. The developer operates no servers and receives no data of any kind. There are no accounts, no analytics, no telemetry and no tracking.

What the extension handles, on your device only

  • Your Linear personal API key, which you paste into the extension's settings. It is stored in Chrome's extension storage and sent only to Linear's own API (api.linear.app) to read the cycle you are viewing.
  • Cycle data from Linear Γאפ issue identifiers, titles, descriptions, estimates, states, assignee names, and their project, initiative and parent issue Γאפ used to draw the bars and the hover details.
  • Calendar feeds you add (for example a HiBob time-off feed, or any Google/Outlook ICS address). Event titles and dates are read to work out who has days off. Titles can include the type of leave; the extension only uses them to match a person's name and count the days.
  • The Linear page you are viewing, only to find which row in the Assignees panel belongs to which person, so the bars can be drawn in the right place.

Fetched data is cached in Chrome's local extension storage for a short time (seconds for Linear, up to 30 minutes for calendars) so the page doesn't re-download it on every view.

Who the extension talks to

  • api.linear.app Γאפ Linear's API, with your key.
  • The calendar addresses you enter, and nothing else. Chrome asks you to allow each calendar's site individually; the extension never has access to all websites.

What we never do

  • Sell, share or transfer any data to third parties.
  • Use data for any purpose other than showing sprint capacity.
  • Use data for creditworthiness or lending decisions.

Removing your data

Clear the fields on the extension's settings page, or uninstall the extension Γאפ Chrome deletes all of its stored data.
